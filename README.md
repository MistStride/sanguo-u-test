# 三国主公适配测试

一个纯前端、零依赖的趣味测试网站：回答十道小题，测出你最适合追随哪位三国主公，以及你最像哪一位历史人物。

## 功能特性

- **十道情境选择题**：覆盖志向、用人、决策、危机、对敌、行事、性情、失败、团队、权力等维度。
- **双维度匹配**：同时算出「最适合追随的主公」与「最像的历史人物」，并给出性格分析与适配度。
- **古风界面**：宣纸 / 朱砂 / 墨金配色，楷体字形，卷轴卡片与印章装饰。
- **响应式**：桌面与手机自适应，操作简洁。
- **一键分享**：优先调用系统分享（手机可直接转发），不支持时自动降级为复制文案；可「再测一次」。

## 本地运行

本项目是纯静态网站，无需安装任何依赖。

**方式一：直接打开**

双击 `index.html` 即可在浏览器中游玩。

**方式二：本地服务器（推荐，分享功能更完整）**

```bash
# 任选其一，在项目根目录执行
python -m http.server 8123
# 或
npx serve .
```

然后访问 `http://127.0.0.1:8123/`。

## 二次开发

- **改题目 / 选项**：编辑 `script.js` 中的 `QUESTIONS` 数组。每个选项含 `t`（题干）、`l`（对应的主公 key）、`f`（对应的人物 key）。
- **加 / 改主公或人物**：在 `LORDS` / `FIGURES` 中增删条目，并让 `QUESTIONS` 里的 `l` / `f` 引用对应的 key 即可，计分逻辑会自动适配。
- **调风格**：配色变量集中在 `style.css` 顶部的 `:root` 中（宣纸、朱砂、墨、金）。

## 部署

因为是纯静态站点，可直接部署到 GitHub Pages、Vercel、Netlify 等任意静态托管服务——把本目录内容作为站点根目录即可。
